CyberGuard 客户端配置知识：Windows、macOS、Android、iOS

一、现代代理客户端通用工作流

尽管 Windows、macOS、Android 与 iOS 四大操作系统在底层权限架构与用户交互上各有千秋，但配合 CyberGuard 使用网络服务时，其通用的配置逻辑是高度统一的。

整个生命周期可以概括为标准的「四步核心工作流」：

  1. 获取订阅凭证：在 CyberGuard 用户后台复制专属的加密订阅链接（URL）；
  2. 导入配置档案（Profile）：在客户端中填入该链接，向订阅服务器发起安全的 HTTPS 同步请求，下载经过结构化解析的节点列表与规则集；
  3. 策略组与分流设定：将运行模式设定为「规则模式（Rule）」，根据业务需要选择具体的出站节点（如香港或日本）；
  4. 启动系统代理或虚拟网卡（TUN）：授权客户端接管操作系统的出站网络流量，完成网络连通性校验。

二、Windows 平台实操：Clash Verge Rev 与 v2rayN

Windows 是开发与桌面办公的核心平台。目前业界最推荐基于 Mihomo (Clash.Meta) 内核且持续积极维护的图形客户端：Clash Verge Rev。

1. 安装与订阅导入流程

  1. 访问开源发布页下载 Clash.Verge.Rev_*_x64-setup.exe，按提示完成安装；
  2. 启动软件，点击左侧菜单栏的「订阅（Profiles）」；
  3. 在顶部输入框中粘贴您的 CyberGuard 专属订阅链接，点击右侧的「导入（Import）」按钮；
  4. 导入成功后，鼠标右键点击新建的配置卡片，选择「启用」。

2. Windows 专属高级技巧与避坑指南

UWP 应用回环隔离问题（Loopback Exemption）

Windows 系统为了安全沙盒隔离，默认禁止所有来自 Microsoft Store 下载的应用（如系统自带邮件、Xbox、OneNote）向本地回环地址（127.0.0.1）发送网络请求。这会导致开启系统代理后，这些 UWP 应用提示“无网络连接”。
解决方法：在 Clash Verge Rev 设置中，找到并点击「Windows Loopback 工具」，点击「Exempt All（全部豁免）」并保存即可。

接管终端命令行流量：对于程序员而言，Windows 系统的代理不会自动对 CMD 或 PowerShell 生效。如需在命令行中加速 git clone 或 npm install，推荐在 Clash Verge Rev 中安装并开启「TUN 模式（虚拟网卡驱动）」，这样整个 Windows 的所有底层 TCP/UDP 流量都会被无缝接管。

三、macOS 平台实操：优雅适配与权限授权

macOS 系统同样完美支持 Clash Verge Rev for Mac 以及 sing-box 原生图形端，全面兼容 Intel 与 Apple Silicon（M1 至 M4 系列芯片）。

1. 关键配置步骤

  • 下载并打开 DMG 安装包，将应用图标拖动至 Applications 文件夹；
  • 首次启动若提示“无法打开，因为无法验证开发者”，请前往「系统设置 - 隐私与安全性」，向下滚动点击「仍要打开」；
  • 在「订阅」页面中粘贴 CyberGuard 订阅链接并下载，切换到「代理」选择香港节点，开启「系统代理」开关；
  • 若需接管 Terminal 或特定本地微服务，开启「TUN 模式」时，系统会弹出授权框，输入 Mac 开机密码以允许安装网络扩展驱动。
Mac 睡眠唤醒后的网络自愈

Mac 笔记本在合盖休眠唤醒后，偶尔会出现系统 DNS 缓存滞留导致网络暂时无响应的现象。此时无需重启系统，只需在终端中执行 sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder 即可快速清空本地 DNS 缓存。

四、Android 平台实操：电量优化与分应用代理

Android 生态高度开放，推荐使用基于现代内核开发的 Clash Meta for Android (CMFA) 或 sing-box Android。

1. 核心操作步骤

  1. 安装官方开源发布的 APK 安装包；
  2. 打开应用，点击「配置 - 新建」，选择「从 URL 导入」；
  3. 输入配置名称（如 CyberGuard），粘贴订阅链接并点击右上角保存；
  4. 返回主界面，点击「配置」选中刚才下载的项目，然后点击最上方的「启动」按钮；
  5. Android 系统会弹出「网络连接请求 / VPN 权限」，点击「确定」允许建立本地虚拟隧道。

2. Android 必备两大优化项

  • 电池优化白名单：国产定制系统（如小米澎湃 OS、华为鸿蒙、vivo OriginOS、OPPO ColorOS）具有严格的后台墓碑机制。请长按客户端图标进入应用信息，将「省电策略」设为「无限制 / 允许后台自启」，并在多任务界面对该应用进行加锁，防止后台切歌或息屏时代理进程被系统强制查杀；
  • 分应用代理（App Routing）：在客户端设置中开启「分应用代理」，勾选需要走专线出国的特定 App（如 YouTube、Chrome、Twitter），其他如微信、高德地图、网银等应用彻底绕过代理，保障国内 App 达到满速直连且极度省电。

五、iOS / iPadOS 平台实操：Shadowrocket 与生态工具

受限于苹果 iOS 闭源生态的策略，中国大陆区 App Store 下架了所有网络代理调试工具。iOS 用户需要使用非大陆地区的 Apple ID 登录 App Store 下载。

1. 常见 iOS 客户端选择

工具名称 上手门槛 特点评价
Shadowrocket (小火箭) 极低 (新手友好) 功能全面，协议兼容性极佳，界面直观，性价比较高
Quantumult X (圈 X) 中等 界面精致，规则分流与重写功能强大，适合极客玩家
Surge for iOS 专业级 网络抓包与调试工业级标杆，授权费用较高
sing-box (iOS) 免费开源 纯开源内核，在 App Store 免费提供下载，适合极客

2. Shadowrocket 极速配置流程

  1. 在 App Store 登录海外账号，搜索并下载 Shadowrocket；
  2. 打开 Shadowrocket，点击右上角「+」号；
  3. 在「类型」下拉菜单中选择「Subscribe」（部分版本显示为订阅）；
  4. 在「URL」栏中粘贴 CyberGuard 订阅链接，备注填写「CyberGuard」，点击右上角「完成」；
  5. 回到首页后向下滑动屏幕触发订阅更新，所有节点将整齐展现；
  6. 点击「连通性测试」测试延迟，选择一个绿色的香港/日本节点；
  7. 将首页下方的「全局路由」设为「配置（Config）」；
  8. 开启最上方的总开关，根据 iOS 系统提示输入锁屏密码以允许添加 VPN 配置。

六、订阅安全与 DNS 防污染进阶知识

完成四端配置后，理解以下两项高阶安全原则能保护您的账户与隐私：

1. 严禁泄露专属订阅 URL

您的订阅链接类似于包含用户名和加密密码的私有通行证。如果将其发送至公开发布的贴吧、QQ 群、GitHub Issue 中，其他人只需将该 URL 复制到自己的客户端，便能在无密码的情况下直接盗用您的节点，耗尽您的套餐高速流量，甚至导致您的账户被安全系统封禁。

2. 科学理解 Fake-IP 与 DNS 防污染

在高级规则分流配置中，通常会看到 enhanced-mode: fake-ip 的设定。这是当前最先进的 DNS 调度机制：客户端在收到系统发起的境外域名解析请求时，并不立即等待远程 DNS 服务器返回真实 IP，而是由本地代理核心瞬间分配一个虚构的保留私网 IP（如 198.18.0.1）。

这样可以彻底杜绝本地运营商的 DNS 投毒与污染，并将域名解析操作延迟到海外出口节点端执行，大幅缩短网页首次建立连接的等待时间（TTFB）。
