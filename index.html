ROUTING TOPOLOGY

直连线路与中转线路对比

直连线路指客户端通过本地运营商公网直接建立与海外服务器的 TCP/UDP 连接。晚高峰期间，由于中国电信/联通/移动的国际公网出口带宽超载，直连常遭遇严重丢包与重传。

中转线路（Relay Transit）则在境内各大核心机房部署中继服务器。用户先连接至国内中转机房（低延迟、内网无丢包），再由中转机房通过特定国际优化带宽转发至海外出口，显著绕开公网拥堵。

公网跳数 12 - 18 跳 (经过公网骨干) 3 - 6 跳 (经中继聚合)
高峰丢包率 10% - 35% 易受拥堵影响 通常控制在 < 2%
BORDER GATEWAY PROTOCOL

BGP 多线智能接入机制

BGP（边界网关协议）是互联网核心自治系统（AS）之间的路由调度机制。优质网络接入端通常采用三网（电信、联通、移动）BGP 多线机房。

无论客户端使用中国电信宽带、中国联通还是中国移动 5G 网络，BGP 会在边缘层自动计算最佳跃点路径，避免单运营商跨境跳数激增带来的 100ms 以上额外握手开销。

单点故障 单机房断网即全断 多线 AS 自治动态倒换
DEDICATED LEASED LINE

IPLC / IEPL 点对点物理专线

IPLC（国际私有租用线路）与 IEPL（国际以太网私网专线）属于最高等级的企业级跨境通信方案。它们是连接两地机房之间的物理光纤租用通道，数据全程运行在封闭的私网内部。

专线不经过任何公共互联网国际出口网关，因此具备完全不受公网拥塞影响、零跨境防火墙拦截干扰、物理级别 0 丢包以及极低抖动的优异特性。

线路类型 普通公网中转 IEPL / IPLC 专线
网络介质 公网 IP 隧道 海底物理光纤内网专线
抖动稳定性 随公网波动 (Jitter 10-50ms) 物理恒定 (Jitter < 2ms)
TELEMETRY ANALYSIS

网络延迟、抖动与丢包深入解析

评估网络质量不能仅看单次 Ping 的数值，而应综合考察以下核心维度：

  • 往返时延（RTT）：光信号在光纤中的传播速度约为 20 万公里/秒。中国沿海到香港物理极限在 15-30ms，到日本在 35-50ms，到美西在 120-140ms。低于该区间的宣称均违背物理规律。
  • 抖动（Jitter）：前后两个数据包到达时间的差异。抖动越小，音视频会议与实时交互体验越稳定。
  • 丢包率（Packet Loss）：丢包会导致 TCP 快速重传并触发拥塞降速，丢包率超过 3% 即可导致 4K 视频明显缓冲。

DEVICE SETUP

全平台客户端配置指南

介绍不同操作系统（Windows、macOS、Android、iOS）常用客户端的通用配置步骤，协助快速建立安全稳定的网络连接。

Windows 平台配置规范

推荐采用基于 Meta / Mihomo 内核的现代现代图形客户端进行配置与规则维护。

Clash Verge Rev v2rayN sing-box GUI
01

获取订阅链接

登录用户中心，在订阅信息区域复制专属的 Clash / Universal 订阅地址。切勿将该私有密钥外泄。

02

导入配置 Profile

启动 Clash Verge Rev，进入「订阅 / Profiles」页面，粘贴订阅 URL，点击「下载 / Import」拉取节点信息。

03

选择分流策略

切换至「代理 / Proxies」标签，建议将分流模式设为「规则 / Rule」，并选中响应低延迟的香港或日本节点。

04

启动系统代理

在客户端主界面开启「系统代理 / System Proxy」，并在设置中可勾选「开机自启」与「静默运行」。

macOS 平台配置规范

支持 Intel 及 Apple Silicon (M1/M2/M3/M4) 原生架构，支持 TUN 虚拟网卡全接管。

Clash Verge Rev (Mac) sing-box for Mac Surge for Mac
01

客户端安装与授权

下载 DMG 文件拖入 Applications，若系统弹出安全提示，需在「系统设置 - 隐私与安全性」允许运行。

02

订阅配置导入

在客户端中新建配置，输入 CyberGuard 订阅地址并完成下载，检查节点健康度（延时测速）。

03

增强模式与 TUN

若需要接管终端命令行（Terminal）或特定开发环境请求，可安装 TUN 辅助网卡驱动。

04

校验网络状态

开启「系统代理」，打开浏览器访问跨境站点测试连接，确认境内流量自动走 Direct 直连。

节点延迟（Round Trip Time）反映的是数据包从本地出发经过中转专线到达目标出口服务器并返回所需的时间，单位为毫秒（ms）。延迟主要受限于光纤物理传输速度与沿途路由跳数。沿海连接香港通常在 20-40ms，日本在 40-70ms，欧美在 130-180ms，均属于符合物理光缆传播规律的优异范围。

不同地区节点速度差异由以下物理与架构因素决定：

  • 海底光缆物理距离不同，距离越远，往返延迟越大，TCP 窗口扩张速度越慢；
  • 目标网站服务器所在位置不同（例如访问亚太媒体选香港/日本就近解析，访问美国本地网站选美西更通畅）；
  • 不同节点的国际出口带宽负载与当地运营商 Peer 互联质量存在动态差异。

在客户端配置管理界面中，右键点击 CyberGuard 配置名称（或点击刷新图标），客户端将向订阅服务器发起 HTTPS 请求，重新同步最新的节点 IP 地址、端口号与加密密钥。建议在遇到节点不可用或官方维护后手动刷新一次。

建议按以下顺序系统排查：

  • 检查系统时钟：打开系统设置开启「自动同步时间」，时钟偏差超过 60 秒会导致 TLS 握手认证直接被拒；
  • 检查套餐状态：登录控制面板确认账户套餐未过期且流量未用尽；
  • 更新订阅配置：重新拉取订阅，排除服务器 IP 变动引起的连接失效；
  • 排查端口冲突：检查本地是否有其他代理或杀毒软件占用了 7890 等本地监听端口。

判断线路稳定性不可单纯看单次极值带宽，而应关注：持续丢包率是否低于 0.5%、网络延迟波动标准差（Jitter 抖动）是否平稳，以及在晚高峰（20:00 - 23:00）骨干网拥挤时段是否依然保持连接不断开。物理专线线路在抗抖动表现上天然优于公网线路。

BGP（边界网关协议）是入口层的路由调度技术，解决不同运营商用户（电信、联通、移动）进入中继机房的最优路径；而 IPLC / IEPL 专线是机房与机房之间的跨境物理光纤内网传输通道，不走公网国际出口，不受跨境网络审查干扰，两者通常协同运作以保证全链路高品质传输。
